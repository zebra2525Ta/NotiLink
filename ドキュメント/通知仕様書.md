# NotiLink プッシュ通知 仕様書

## 概要

毎時1回、NotionのスケジュールDB・買い物リストDB・天気情報をもとに、Groq（AI）が通知文を生成してスマホに送信する。

---

## アーキテクチャ

```
cron-job.org（毎時）
    ↓ POST /api/cron/check（Bearer認証）
    ├─ Redis から Notionトークン取得
    ├─ Notion DB 照会（スケジュール・買い物リスト）
    ├─ 天気API 照会
    ├─ Groq で通知1件生成
    └─ web-push でスマホに送信
              ↓
        Service Worker (sw.js)
              ↓
        スマホ通知
```

---

## 送信時間帯

**8:00〜23:00（JST）毎時1件、計16件/日**

cron-job.org の設定：毎時60分間隔

---

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `public/sw.js` | Service Worker本体。push受信・通知クリック処理 |
| `app/components/PushSetup.tsx` | 通知許可バナー・SW登録・テストボタン |
| `app/api/push/subscribe/route.ts` | サブスクリプション＋Notionトークンを Redis に保存 |
| `app/api/push/test/route.ts` | 即時テスト送信（セッション認証） |
| `app/api/cron/check/route.ts` | 毎時実行。Notion照会→AI生成→送信 |
| `lib/push.ts` | Redis接続・web-push設定・sendPush関数 |

---

## Redis データ構造

| キー | 内容 | TTL |
|------|------|-----|
| `push:subscription` | Web Push サブスクリプションオブジェクト | なし |
| `push:token` | Notion アクセストークン | なし |

---

## 通知生成ロジック（cron/check）

1. `push:subscription` が Redis になければ終了
2. `push:token` から Notionトークン取得
3. Notion DB を検索し以下を取得：
   - **スケジュールDB**（タイトルに「スケジュール」「予定」「カレンダー」を含むDB）→ 当日の予定
   - **買い物リストDB**（タイトルに「買い物」「ショッピング」を含むDB）→ 未購入アイテム（購入済み✓を除く）
4. `/api/weather` から天気情報取得
5. Groq（llama-3.3-70b-versatile）に現在時刻・Notion情報・天気を渡して通知1件生成
6. `web-push.sendNotification()` で送信

---

## 通知テスト

アプリ上の「通知テスト」ボタン（右下）を押すと即時送信。  
`/api/push/test` をPOSTで呼び出す（ログイン必須）。

---

## 初回セットアップ手順

1. アプリを開く → 「Naviからの通知を受け取る」バナーで **許可する** をタップ
2. 自動的にサブスクリプションとNotionトークンがRedisに保存される
3. 以降は毎時自動送信（翌朝8時から）

許可済みの場合はアプリを開くだけで自動再登録される。

## 必要な環境変数（Vercel）

| 変数名 | 説明 |
|--------|------|
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | VAPIDパブリックキー |
| `VAPID_PRIVATE_KEY` | VAPIDプライベートキー |
| `VAPID_SUBJECT` | `mailto:メールアドレス` |
| `UPSTASH_REDIS_REST_URL` | Upstash Redis URL |
| `UPSTASH_REDIS_REST_TOKEN` | Upstash Redis トークン |
| `CRON_SECRET` | cron-job.orgからのリクエスト認証トークン |
| `GROQ_API_KEY` | Groq APIキー |

---

## cron-job.org 設定

| 項目 | 値 |
|------|----|
| URL | `https://noti-link.vercel.app/api/cron/check` |
| メソッド | GET |
| 間隔 | 60分 |
| ヘッダー | `Authorization: Bearer {CRON_SECRET}` |

## iOS 対応について

- iOS 16.4以上 + PWA（ホーム画面に追加済み）が必須
- Safariブラウザからは通知不可
- ログイン時はSafariで行い、完了後PWAを再起動する
